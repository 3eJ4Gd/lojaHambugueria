    Preços e exibição

    Acesso ao painel

    Limite de segurança: a senha fica gravada neste navegador e o acesso é local. Não é adequada para proteger dados sensíveis. Antes de publicar, aplique uma senha no servidor para esta pasta.

    Gestão de pedidos

    Pedidos enviados pelo site. Atualize o status conforme o atendimento acontece.

    Dados e backup

    As alterações ficam gravadas neste navegador. Exporte o JSON para aplicar em outro dispositivo ou tornar as mudanças permanentes no arquivo de configuração.

    Exportar configuração

    Gera um arquivo com produtos, categorias, adicionais, loja e horários.

    Importar configuração

    Cole um JSON exportado anteriormente. A importação substitui a configuração atual.

    Como tornar definitivo: edite js/data.js com os valores exportados, ou apague o registro brasa_db_v1 do armazenamento local para voltar ao conteúdo do arquivo.

    Restaurar

    Irreversível: as ações acima apagam os dados gravados neste navegador.
